# Notas de uso

- Usar **una sola versión por envío** (evitar mandar varias variantes al mismo contacto).
- **Productos (A)** vs **Servicios (B):** no mezclar en el mismo mensaje salvo que el contacto pregunte por ambos.
- Productos: la versión "beneficios" funciona mejor si aún no usan sistema; la corta para estados/broadcast.
- Servicios: B1 para primer contacto serio; B4–B7 cuando ya sabes qué necesitan; B2 para estados.
- Mantener siempre el mismo CTA (`inventtia.com` / `sales.html` + WhatsApp) para no fragmentar la marca.
