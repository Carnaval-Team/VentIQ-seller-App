# Mensajes WhatsApp — Dar a conocer Inventtia

Objetivo: presentar qué es Inventtia y las ventajas que trae para el negocio
(no es un recordatorio para clientes activos, es difusión para que la gente
conozca el producto). Listos para copiar y pegar en WhatsApp (el `*texto*`
se muestra en negrita).

**CTA único:** inventtia.com · WhatsApp +53 63464544

## Versión completa (presentación del producto)

```
Hola 👋 Te presentamos *Inventtia*, el sistema para llevar tu negocio desde
el celular o la computadora — cobro en el mostrador y gestión completa,
todo conectado.

🧾 *Inventtia Caja* (para vender)
• Cobro rápido: efectivo, transferencia y multi-moneda
• Funciona *sin internet* — vende offline y sincroniza sola cuando vuelve la señal
• Apertura y cierre de turno con cuadre de caja automático
• Tickets de venta y control de vendedores

📊 *Inventtia Gestión* (para controlar)
• Inventario en tiempo real, por almacén y ubicación
• Precios y costos bajo control, con márgenes claros
• Reportes de ventas del día, la semana o el mes
• Recepciones, ajustes, transferencias y consignaciones

*Ventajas para tu negocio:*
✔️ Dejas de perder ventas por falta de internet
✔️ Sabes en todo momento cuánto tienes en caja y en inventario
✔️ Ahorras tiempo en cierres, reportes y control de personal
```

## Notas de uso

- Usar **una sola versión por envío** (evitar mandar las tres variantes al mismo contacto).
- La versión "beneficios" funciona mejor para negocios que aún no usan ningún sistema.
- La versión corta es ideal para reenvíos masivos o estados/broadcast.
- Mantener siempre el mismo CTA (`inventtia.com` + WhatsApp) para no fragmentar el mensaje de marca.
